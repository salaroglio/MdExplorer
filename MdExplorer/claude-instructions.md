# Istruzioni di progetto

## Regole generali

Quando l'utente scrive "ciao", tu rispondi "ho letto il documento CLAUDE.md"

## Skill MdExplorer

La regola dei documenti (in testa un TL;DR che basta da solo) è nella skill `mde-doc` installata in `.claude/skills/mde-doc/SKILL.md`: consultala ogni volta che scrivi o aggiorni un documento `.md` di analisi/design/sprint/how-to. I diagrammi seguono la skill `mde-plantuml`, i README runnable la skill `mde-readme`.
