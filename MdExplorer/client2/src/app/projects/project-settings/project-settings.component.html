Validation Rules
Rule #1: Check H1 matches filename

When enabled, verifies that the H1 heading in each Markdown file matches the filename and automatically adds YAML frontmatter to markdown files. This helps maintain consistency between file names and document titles.

Note: This feature should be disabled when using GitHub Compatible Mode, as GitHub doesn't recognize MdExplorer's custom YAML frontmatter format.

GitHub Compatibility
GitHub Compatible Mode

When enabled, uses GitHub-compatible markdown rendering (no PlantUML, interactive emoji, etc.). Disable for full MdExplorer features when working in a team environment.

Link Indexing
Enable Link Indexing

When enabled, MdExplorer indexes all links inside markdown files to track cross-references and automatically recalculate paths when files are moved or renamed.

Note: Disabling this setting improves performance on large projects but removes link reference tracking and automatic link recalculation on file move/rename. Changes take effect on next project reload.

View Options
Sticky scroll (VS Code-style parent folders)

When enabled, parent folders remain visible at the top of the file tree while scrolling — similar to VS Code's file explorer behavior.
