help_outline Aiuto: Come configurare il remote

1. Crea il repository sul tuo provider Git

Vai su GitHub, GitLab, o il tuo server Git e crea un nuovo repository vuoto.

2. Copia l'URL del repository

Copia l'URL HTTPS (es. https://github.com/utente/repo.git)

3. Inserisci le tue credenziali

Username e password, oppure un Personal Access Token.

4. Verifica e Configura

Usa "Verifica Connessione" per testare, poi clicca "Configura".
