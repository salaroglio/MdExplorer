# Empty project

The folder you choose becomes an MdExplorer project **as it is**: your files stay where they are.

---

## What MDE adds

- the `.md/` folder with the Word and PDF templates
- `.development.yml`, the group's shared configuration
- the skills and agents for the engine you choose (Claude, Copilot, opencode)
- git, if you ask for it

---

## When to choose it

- you already have documentation and want to work on it with MDE
- you want to start from scratch, without a method
- a method can be added later, from the project settings
